Observable by design

Structured responses and bilingual events make every step inspectable instead of hiding system changes behind a black box.

One operation at a time

A process-wide lock rejects concurrent repairs, reducing races across services, caches, and reboot-sensitive actions.

Built for verification

The core is exercised by cross-platform unit tests; Windows-specific behavior is mocked in CI.
